# С днём рождения, Снежана!

Праздничный одностраничный сайт-поздравление: письмо, пожелания, торт с интерактивными свечами и конфетти.

## Файлы

- `index.html` — разметка и тексты поздравления.
- `styles.css` — оформление, анимации и адаптив.
- `script.js` — появление секций, конфетти, свечи на торте.

## Как открыть

Откройте `index.html` в браузере. Внешняя зависимость только одна — шрифты Google Fonts; без интернета сайт продолжит работать на системных шрифтах.

## Что можно поменять

- Текст письма и пожелания — в `index.html`.
- Подпись и имя — там же, в hero и финальном блоке.
- Палитра — CSS-переменные в начале `styles.css` (`--rose`, `--lilac`, `--gold` и другие).
- Количество свечей — добавьте или уберите кнопки `.candle` в секции `#cake`.
